# Rock Paper Scissors Game

A simple Python game where you play Rock, Paper, Scissors against the computer.  

## How to Play

1. Run the Python file.
2. Enter rock, paper or scissors.
3. See who wins each round.
4. Play multiple rounds and check the scores.
5. Choose to play again or exit.

## Features

- Tracks your score and computer’s score
- Supports multiple rounds
- Input validation
- Replay option

## How to Run

```bash
python rock_paper_scissors.ipynb
